Static visualizations are flat & show the data in one set format, such as bar chart or line plot. Basically what you is what you get. Interactive visualizations allow the user to click,zoom in, hover over data points, & view this info in different ways.
Dashboards are useful for real time data because they make it easier to see updated info in one place. It can help users notice quickly notice the changes made, compare the data, & focus on the info  that is most important to them.
